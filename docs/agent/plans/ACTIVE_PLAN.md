## Objective

두 가지를 동시에 한다.
1. **표면의 문법을 하나로** — 반경·깊이·재료·간격이 하나의 규칙에서 나오고, 손이 닿는 모든 곳이 같은 스프링으로 반응한다.
2. **바뀐 것은 말한다** — 특히 **A/B/C 전환**. 문서가 통째로 갈리는데 화면이 조용하면 사용자는 자기가 어느 판에 있는지 잃는다.

## Verifiable End State

- **M1 동심 반경** — 반경 토큰이 `stage > card > control > chip` 사다리를 이루고, 중첩된 표면은 `안 = 밖 − 패딩`을 따른다. 테스트가 사다리의 단조성과 선언된 중첩 관계를 고정한다.
- **M2 손맛** — hover/press가 색만 바뀌던 컨트롤들이 스프링으로 눌리고 되돌아온다. 빈번한 것(칩·툴바 버튼) bounce 0, 드문 것(변형 전환·모달) 0.25~0.3. `prefers-reduced-motion`에서 변형은 사라지고 색만 남는다. **raw cubic-bezier 금지 규칙 유지.**
- **M3 "무엇이 바뀌었는지"** — A/B/C를 바꾸면 (a) 보드가 한 번 숨을 쉬고(scale+fade, 스프링), (b) 어느 판인지 토스트가 말하고, (c) 칩이 이동한다. 같은 장치를 **문서 정체성이 바뀌는 다른 자리**(불러오기·새로 시작·포메이션 적용·되돌리기로 판이 갈릴 때)에도 쓴다. 재생 중이거나 `reducedMotion`이면 모션 없이 토스트만.
- **M4 비율** — 간격이 하나의 리듬을 따르고, 보드 점유율은 **현재 이상**을 유지한다(실측으로 증명).
- **M5 게이트** — 5게이트 PASS + 브라우저 프로브 전부 PASS + 두 테마 대비 회귀 없음(feel-lab).

## Non-Goals

- 엔진·도메인·문서 스키마 불변. 전술 모션(스프링 아님) 불변.
- 도킹 패널에 backdrop-filter 도입 금지(A-04a).
- 고채도 다색 버튼 금지(VDR-0001 배제 3).
- 패널 폭 하한 222px 아래로 내리지 않음(한국어 줄바꿈 실측).
